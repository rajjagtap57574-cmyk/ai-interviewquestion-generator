Netlify Deployment Instructions

This web application is configured with Netlify Functions to keep the AI_API_KEY safe. Here is how to deploy it:

  1. Click "Download Netlify .ZIP" at the top right of this page to get the organized project files.
  2. Unzip and upload the folder to a public or private GitHub Repository.
  3. Log into Netlify and select "Add new site" → "Import an existing project".
  4. Connect your GitHub account and select your repository.
  5. In Netlify Site Settings → Environment Variables, add key: AI_API_KEY with your Gemini API Key value.
  6. Deploy site! Netlify automatically detects the netlify.toml and deploys the function at /.netlify/functions/generateQuestions.
